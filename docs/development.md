# Разработка

## Структура

```
backend/           сервер на Node.js
  src/routes/      HTTP-эндпоинты: вход, чеки, статистика, рейтинг, друзья
  src/services/    вся логика: распознавание, разбор чека, категории,
                   рейтинг, зарплатные циклы, защита от накрутки
  src/db/          схема SQLite и запросы
  src/bot/         бот: кнопка запуска приложения и вечерние сводки
  test/            32 теста на логику и на HTTP-слой

frontend/          интерфейс на React
  src/components/  экраны и элементы
  src/api/         типизированный клиент к серверу
  src/telegram.ts  обёртка над Telegram Web App
```

## Команды

| Где | Команда | Что делает |
|---|---|---|
| backend | `npm run dev` | сервер с перезапуском при изменениях |
| backend | `npm run dev:all` | сервер и бот одной командой |
| backend | `npm test` | тесты |
| backend | `npm run typecheck` | проверка типов |
| frontend | `npm run dev` | интерфейс с горячей перезагрузкой |
| frontend | `npm run build` | сборка |

В VS Code то же самое доступно через `Ctrl+Shift+P` → `Tasks: Run Task`.

## Как считается рейтинг

Шкала построена вокруг середины: 5.00 — «тратишь как обычный человек».
Каждое удвоение трат добавляет 2.5 балла, поэтому вчетверо больше нормы —
это потолок 10.00, а половина нормы — 2.50.

Считается не накопленная сумма, а темп: траты за месяц делятся на прожитые дни
и разгоняются до полного месяца. Иначе первого числа любой выглядел бы
экономным, а тридцатого — транжирой просто потому, что месяц кончается.

Если указан доход, результат дополнительно подкручивается на 10% в обе стороны
в зависимости от того, где человек находится в зарплатном цикле.

Код: `backend/src/services/rating.ts`.

## Как распознаётся чек

1. Кадр увеличивается, обесцвечивается, растягивается контраст — термочек
   это серый текст на сером фоне, без обработки он не читается.
2. Определяется ориентация: длинный чек часто снимают боком, поэтому на
   уменьшенных копиях пробуются все четыре поворота и выбирается тот, где текст
   больше похож на чек.
3. Ищется фискальный QR-код — в нём точные сумма и дата, им доверяем больше,
   чем распознанному тексту.
4. Текст разбирается построчно: отсеиваются реквизиты и адреса, цена берётся
   последней в строке, подхватывается со следующей строки (на чеках сетей
   название идёт отдельно от цен).
5. Если сумма позиций не сходится с итогом — человеку показывается
   предупреждение, а не молчаливо неверные данные.

Код: `backend/src/services/` — `imagePrep.ts`, `ocr.ts`, `qr.ts`, `parser.ts`.
