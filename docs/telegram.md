# Запуск внутри Telegram

Приложение работает и как обычный сайт, но задумано как мини-приложение
Telegram: тогда нет регистрации, а интерфейс подстраивается под тему мессенджера.

## Что понадобится

1. **Бот.** В Telegram найти [@BotFather](https://t.me/BotFather) → `/newbot` →
   придумать имя и username (должен заканчиваться на `bot`). В ответ придёт токен
   вида `123456789:AA...` — это пароль от бота, его нельзя публиковать.

2. **Публичный адрес.** Telegram открывает мини-приложения только по `https`,
   поэтому `localhost` не подойдёт. Для разработки проще всего временный туннель:

   ```bash
   cloudflared tunnel --url http://localhost:5173
   ```

   Команда напечатает адрес вида `https://что-то.trycloudflare.com`. Он живёт,
   пока команда запущена: перезапустил — адрес сменился.

## Настройка

Скопировать `backend/.env.example` в `backend/.env` и заполнить:

```
BOT_TOKEN=токен от BotFather
BOT_USERNAME=имя_бота_без_собачки
MINI_APP_URL=https://адрес-туннеля.trycloudflare.com
```

Адрес — целиком, с `https://` и без слэша в конце.

## Запуск

Три терминала:

```bash
cloudflared tunnel --url http://localhost:5173   # туннель, не закрывать

cd frontend && npm run dev                        # интерфейс

cd backend && npm run dev:all                     # сервер и бот вместе
```

Затем написать боту `/start` и нажать «Открыть трекер».

## Частые проблемы

**`ETIMEDOUT` на api.telegram.org.** Серверы Telegram недоступны из этой сети
напрямую. Включить VPN либо указать прокси в `.env`:

```
BOT_PROXY=http://127.0.0.1:10809
```

**Кнопка ведёт на несуществующий адрес.** Адрес вшивается в сообщение в момент
отправки, поэтому после смены туннеля старые сообщения остаются со старой
ссылкой. Нужно заново отправить боту `/start` — или нажать кнопку меню рядом
со скрепкой, она обновляется автоматически.

**Камера не открывается.** Браузеры дают доступ к камере только по `https`.
Внутри Telegram и по адресу туннеля всё работает, по локальному адресу
в сети (`http://192.168...`) — нет.
