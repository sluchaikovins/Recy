# Recy — трекер трат со шкалой шопоголизма

Мобильное веб-приложение: фотографируешь чек, приложение распознаёт покупки
и показывает, на что уходят деньги. Работает как приложение внутри Telegram —
устанавливать ничего не нужно.

## Зачем это нужно

Люди плохо представляют, куда уходят их деньги. Банковское приложение
показывает «Магнит — 1 280 ₽», но не говорит, что из этой суммы 700 ₽ — сладкое.
Вести учёт вручную почти никто не выдерживает: это скучно и долго.

Recy убирает рутину — вся трата записывается за одну фотографию чека — и
добавляет то, чего нет у банков: **шкалу шопоголизма**. Приложение оценивает
твои траты от 1.00 до 10.00, где 5.00 — «тратишь как обычный человек». Это
превращает скучный учёт в понятную и слегка ироничную оценку, которой хочется
поделиться с друзьями.

## Что умеет

- **Сканирование чека камерой.** Кадр обрабатывается и распознаётся, товары
  раскладываются по категориям автоматически.
- **Чтение фискального QR-кода.** В российских чеках есть QR с точной суммой
  и датой — приложение ловит его прямо в видоискателе, поэтому сумма верна даже
  когда текст на чеке смят и читается плохо.
- **Шкала шопоголизма** с учётом темпа трат и зарплатного цикла: тратить сразу
  после зарплаты не то же самое, что за день до неё.
- **Статистика**: расходы по дням, распределение по категориям, топ покупок,
  сравнение с прошлым месяцем.
- **Регулярные платежи** — связь, подписки, аренда записываются сами раз в месяц.
- **Лидерборд друзей** с защитой от накрутки: в зачёт идут только чеки,
  подтверждённые фискальным QR.
- **Вечерняя сводка от бота**: сколько потрачено за день и на сколько дней
  хватит денег до зарплаты.

## Как это устроено

Три части, каждая делает свою работу:

```
Telegram ──▶ мини-приложение (React)
                    │
                    ▼
              сервер (Node.js) ──▶ распознавание чека (Tesseract + QR)
                    │
                    ▼
              база данных (SQLite)
```

**Мини-приложение** открывается прямо внутри Telegram: регистрации нет, человек
уже вошёл. Интерфейс подстраивается под тему мессенджера и умеет работать
с камерой телефона.

**Сервер** принимает фотографию, готовит её к распознаванию (увеличивает,
обесцвечивает, сам определяет, каким боком снят чек), достаёт текст и фискальный
QR-код, раскладывает покупки по категориям и считает рейтинг.

**База** хранит траты, доходы и связи между друзьями. Фотографии чеков лежат
рядом с ней на сервере и никуда не передаются.

Подробнее — в [docs/development.md](docs/development.md): структура проекта,
как считается рейтинг и как разбирается чек.

## Технологии

| Часть | Что использовано |
|---|---|
| Интерфейс | React, TypeScript, Vite |
| Сервер | Node.js, Express, TypeScript |
| База | SQLite |
| Распознавание | Tesseract.js (текст), jsQR (фискальный QR) |
| Обработка изображений | Jimp |
| Бот | grammY |
| Тесты | встроенный тест-раннер Node.js, 32 теста |

Внешних платных сервисов нет: распознавание работает на своём сервере,
шрифты лежат в проекте. Проект целиком запускается на одном компьютере.

## Как запустить локально

Нужен установленный [Node.js](https://nodejs.org) версии 20 или новее.

```bash
git clone <адрес репозитория>
cd Recy

# сервер
cd backend
npm install
cp .env.example .env          # заполнить JWT_SECRET, остальное можно оставить
npm run dev                   # http://localhost:4000

# интерфейс — во втором терминале
cd frontend
npm install
npm run dev                   # http://localhost:5173
```

Открыть `http://localhost:5173`, зарегистрироваться любой почтой — данные
хранятся только на твоём компьютере.

Тесты: `npm test` в папке `backend`.

Чтобы приложение открывалось внутри Telegram, нужен бот от
[@BotFather](https://t.me/BotFather) и публичный адрес — подробности
в [docs/telegram.md](docs/telegram.md).

## Статус

**Рабочий прототип.** Всё описанное выше работает: сканирование чеков,
рейтинг, статистика, бот, регулярные платежи. Приложение проверено на реальных
чеках из магазинов.

Что ещё не сделано:

- Не развёрнуто на постоянном сервере — запускается локально.
- Распознавание текста ошибается на сильно смятых и выцветших чеках.
  Фискальный QR-код это компенсирует: сумма и дата всё равно читаются точно.
- Нет английской версии интерфейса.

## Что планируется дальше

1. **Развернуть на сервере**, чтобы приложением можно было пользоваться
   без запуска на своём компьютере.
2. **Приём фотографий прямо в чате с ботом** — трата записывается, не открывая
   приложение.
3. **Сравнение цен**: одни и те же товары в разных магазинах по истории чеков.
4. **Версия вне Telegram** — как обычный сайт, устанавливаемый на домашний экран.
