# Шрифт названия

Здесь лежит файл фирменного шрифта, которым набрано название **Recy**.

Назови файл `recy-brand.woff2` (подхватятся также `.otf` и `.ttf`) — подключение уже
прописано в `src/styles.css` (`@font-face { font-family: 'Recy Brand' }`). Пока файла
нет, название набирается запасным Unbounded и приложение работает как обычно.

## Почему файла нет в репозитории

Сейчас используется **Unifix SP Demo** (автор Саша Павленко, pavljenko.ru).
Это shareware-версия, и её readme прямо говорит: бесплатное скачивание не даёт права
на коммерческое использование, сайты, приложения, логотипы и распространение.
Поэтому файл добавлен в `.gitignore` — чтобы репозиторий его не раздавал.

Для личной разработки просто положи файл сюда. Для публичного запуска понадобится
полная лицензия у автора — либо шрифт со свободной лицензией (SIL OFL).

## Как конвертировать

Woff2 весит в разы меньше OTF (16 КБ против 240 КБ) и грузится быстрее:

```bash
pip install fonttools brotli
python3 -c "from fontTools.ttLib import TTFont; f=TTFont('шрифт.otf'); f.flavor='woff2'; f.save('recy-brand.woff2')"
```
